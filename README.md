## Repository Structure

Here is a quick guide to navigating the folders in this vault:

* **`/0 day Workshop`**: Materials, slides, and network penetration testing labs from workshops I've designed, organized, or participated in.
* **`/Cert`**: A centralized vault of my verified academic credentials and sanitized industry assets.
* **`/Uni Project`**: My core university coursework, laboratory projects, and architecture designs, including:
    * `Computer Network`: Routing, switching, and protocol analysis.
    * `Database-Project`: Database architecture, SQL queries, and management.
    * `Malware Analysis`: Hands-on static and dynamic analysis, including low-level decompiled code investigation.
    * `NISD`: Network Security Infrastructure and Design (features my Layer 7 WAF implementation and Centralized Security Watchtower deployments).
    * `Programming C++`: Object-oriented programming projects and exercises.
    * `data-structure-project`: Core data structures and algorithmic implementations.
