# 🪪 Verified Credentials & Certifications

This directory serves as the centralized, cloud-hosted storage for my official cybersecurity certifications, academic transcripts, and Capture The Flag (CTF) achievements. 

### 📁 Directory Structure
* **/Professional:** Industry-standard certifications (e.g., CompTIA Security+, CBTP).
* **/Academic:** Official university transcripts and diplomas.
* **/CTF:** Verification of competitive placements and event participation.

> **Note on Infrastructure:** The files in this directory are dynamically fetched via the GitHub Git Trees API and rendered securely on my [interactive frontend portfolio](https://alice1nrootland.github.io).
